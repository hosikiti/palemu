# Palemu

Portuguese vocabulary flashcards for baroque music, built with React, TypeScript, Vite, Tailwind CSS, and localStorage.

## Development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

## Deploy

```sh
pnpm deploy
```

`pnpm deploy` builds the app and publishes `dist/` to the `gh-pages` branch for GitHub Pages.
